# LAP qualification demo

A basic local browser demo of the Home Credit Loan Against Property qualification conversation. It uses only Python's standard library: no `pip install`, API keys, database, or phone service are needed.

## Start it

Open PowerShell in this folder and run:

```powershell
py app.py
```

Then open <http://127.0.0.1:8000>. Press `Ctrl+C` in PowerShell to stop it. Demo answers stay in memory and are cleared when the app stops.

This version is for trying the conversation flow locally. It does not place calls or send answers to an external service.
